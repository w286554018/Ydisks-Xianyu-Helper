# 跨账号复制发布（商品铺货）

## 需求
用户管理多个闲鱼账号，需要把账号 A 已发布的商品复制发布到账号 B/C…（多账号铺货）。

## 已确认决策（Grill 2026-11-01）
1. 入口：商品列表多选批量复制 + 详情单个复制（两期合一期做，列表多选优先）
2. 图片：复用本地快照中的平台 CDN URL（item_detail.detail_params.imageInfos），worker 现成下载回调拉取后逐账号上传
3. 发布节奏：串行 + 间隔抖动（复用批量铺货 worker 现有节奏与节流）
4. 内容可预览可改：弹窗预填标题/描述/价格，可修改后发布（用户自行差异化，不做自动改写）
5. 详情来源：本地 item_info 快照，零平台请求
6. 执行形态：复用批量铺货批次（行=目标账号），进度/取消/重试全部沿用现有能力
7. 预检：批次预检（账号归属/字段校验，不发 MTOP）；登录态失效由发布期会话恢复既有机制处理

## 验收标准
1. 商品列表可多选商品，弹窗选目标账号（可多选），预填内容可编辑
2. 确认后生成批量铺货批次，进度条逐行显示每账号状态
3. 全程新增平台请求为零（图片为 CDN 下载，发布走既有节流）
4. 多规格源商品明确提示暂不支持
5. make check 全绿
