# 11-09-local-browser-fetch（本机真实浏览器抓取助手）

## Goal

让「竞品详情 → AI 改写 → 一键搬运」在生产可用：详情抓取改由**用户本机的真实浏览器**执行，
服务器侧复用既有详情缓存、AI 改写、图片入库与搬运预填链路。

## 背景与已确认事实（实测）

- 平台接口 `mtop.taobao.idle.pc.detail` 对服务器侧自动化浏览器**确定性判罚**：
  返回 `FAIL_SYS_USER_VALIDATE` / `RGV587_ERROR::SM::哎哟喂,被挤爆啦,请稍后重试`，
  并要求在会话内完成人机验证；自动滑块 3+3 次全部失败（错误码每次都不同）。
- 已否证的假说（均有实机证据）：出口 IP（住宅宽带仍失败）、无头环境（`PERSISTENT HEADED` 仍失败）、
  账号会话新旧（扫码 + 人脸验证的新会话仍失败）。
- 同一账号、同一浏览器的**搜索接口正常**。受影响范围仅限详情链路；
  市场情报搜索/选品、关注词、卖家榜、商品列表、自动发货等不受影响。

## Requirements

- R1 抓取执行位置：在用户本机的真实浏览器中打开闲鱼商品页，取详情数据。
- R2 浏览器载体与登录方式：**用户已安装的 Google Chrome（157）+ 专用 `--user-data-dir` 目录**
  （独立于日常 profile，如 `~/Library/Application Support/ydisks-fetch-chrome`）；
  用户在助手窗口中**手动登录一次**闲鱼，之后常驻复用该登录态。
  - 背景约束：Chrome 136+ 拒绝在默认 profile 上启用 `--remote-debugging-port`，故必须独立 profile；
    且用户日常闲鱼登录态在火狐中，Chrome 日常 profile 无法自动复用。
- R3 服务器 ↔ 助手通信：助手在 Mac 上只绑 `127.0.0.1` 起小 HTTP 服务，经**用户 Mac 主动发起的
  `ssh -R` 反向隧道**暴露到服务器 `127.0.0.1`；请求带**共享令牌**鉴权；详情实时返回。
- R4 降级语义：命中 7 天缓存直接返回缓存（现有行为）；未命中才调用助手；
  助手未连接 / 超时 / 未登录闲鱼时返回 **503 + 专属错误码 + 可操作提示**，
  **不回退**服务器侧浏览器（回退必然 55s+409，且加重平台风控）。
- R5 落地位置：助手**只回详情 JSON**；详情缓存、AI 改写、图片下载入库、搬运预填全部保持在服务器侧。
- R6 安全边界：助手端口只绑回环；**接口只接受 `item_id`，由助手自己拼详情页 URL**
  （绝不接受任意 URL，避免成为通用代理/SSRF 跳板）；共享令牌存 0600 文件且不落日志；
  不新增任何公网监听。

## Acceptance Criteria

- [ ] Mac 侧助手可启动，自动拉起/检测专用 profile 的 Chrome（`--remote-debugging-port`），
      并能对指定 `item_id` 返回详情 JSON（含标题、价格、描述、图片列表、卖家信息）。
- [ ] 服务器 `GET /api/v1/market-intel/items/{item_id}/detail` 在助手在线时返回 200 + 详情，
      与既有缓存/AI 改写/搬运链路打通（端到端实测）。
- [ ] 7 天缓存命中时不向助手发请求（有测试证明）。
- [ ] 助手未启动 / 令牌错误 / 未登录闲鱼 三种情况分别返回明确状态与专属错误码，
      且**不触发**服务器侧浏览器（有测试证明）。
- [ ] 助手接口收到非 `item_id`（如 URL、路径穿越）时拒绝，且不发起任何出站请求（有测试证明）。
- [ ] 令牌不出现在服务器日志、助手日志、API 响应与错误消息中（有测试证明）。
- [ ] 助手仅监听 `127.0.0.1`；服务器侧只依赖回环可达，不新增公网端口（部署文档记录）。
- [ ] Go 门禁：`go test ./...`、架构门禁、`commentlint`、`make api-check` 全通过；
      新增/修改的确定性函数与错误分支均有测试，Go 覆盖率不低于 90%。
- [ ] `api/openapi.yaml` 更新详情接口的 503 契约并补充契约测试。

## 术语

- **本机抓取助手（local fetch agent）**：运行在用户 Mac 上的小程序，用本机真实 Chrome 抓取闲鱼商品详情。
- **专用 profile**：助手使用、与用户日常浏览互不干扰的独立 Chrome 用户数据目录。
- **详情**：闲鱼商品页面自发请求 `mtop.taobao.idle.pc.detail` 返回并解析后的结构化商品数据。
